# 🏥 VisiPulse

نظام مراقبة ذكي متكامل لإدارة المعدات والموارد الطبية وتتبع حالتها التشغيلية، مصمم خصيصاً للبيئات الصحية لضمان استمرارية العمل ومطابقة معايير الاعتماد والجودة.

---

## 3) هيكلة الأدوار والصلاحيات (RBAC)

يوفر النظام صلاحيات تحكم دقيقة تعتمد على الدور الوظيفي لضمان أمان وخصوصية البيانات الطبية:

| الدور | الاسم المستخدم | المستوى | الإمكانيات والمهام |
| :--- | :--- | :--- | :--- |
| **it** | `it_admin` | تقنية المعلومات | الصحة الإلكترونية، الدعم الفني، البنية التحتية والشبكات، الأنظمة والتطبيقات، سجل التدقيق الأمني، إدارة تنقيط الخطط. |
| **executive** | `hospital_director` | الإدارة العليا | اعتماد القرارات الاستراتيجية، تقارير الاتفاقية الإدارية (SLA)، ومستوى الخدمة (KPI)، مؤشرات الأداء. |
| **employee** | `employee1` | موظف | الإنذار الاستباقي ورصد الأعطال، إرسال البلاغات ومتابعتها. |

> **ملاحظة:** تمت إضافة نسق تصميم مستوحى من بوابة 3BHS في متطلبات النظام، بحيث يتم رفع نتائج جودة منشأة الأعشاب وتأكيد الطلب عنها، كما تمت إضافة الصلاحيات المرتبطة بإدارة تقنية معلومات الحوسبة الآلية ودور إدارة الأجهزة والوصول (IAM) في المنشأة.

---

## 4) الضوابط الأمنية المنظمة

* **سياسة كلمات المرور الحازمة:** 12 كارد كحد أدنى، أرفق حرف كبير + صغير + رقم + رمز خاص، منع استخدام أسماء المستخدمين، رفض كلمات المرور الشائعة، منع استخدام آخر 8 كلمات مرور، وانتهاء صلاحيتها كل (90) يوم قابلة للتعديل عبر (env).
* **تشفير حلقة التوثيق (TLS/HTTPS):** لحماية بيانات الجلسات ووسائط النقل (WAF)، واختبار اختراق دوري.
* **سiyasات تنظيمية وإجرائية موثوقة:** (تصنيف بيانات، استمرار أعمال، تدريب توعوي) مكتملة للضوابط التقنية.
* **استقلال SQLite بقاعدة بيانات مؤسسية:** (PostgreSQL/SQL Server) مع نسخ احتياطي واستعادة مختارة عند الانتقال إلى بيئة بناء حقيقية متعددة النقاط.

---

## 5) ملاحظة أمان حول النطاق التنظيمي

هذا النظام بمحتواه سيطرة شبكية وموافقة مع معايير CBAHI المحلية وNCC ECA الحامية للحدود والوصول وسجلات الأحداث، كأدلة تأكيد شهادة انتقال أو ضماناً لاختراق نظام تشغيل. كذلك يمثل أدوات عناصر تنظيمية وتقنية واستعادة عناية نطاق تطبيق يراوح بتقنية تشفير حفظ.

* **تكامل مع بيئة مصادقة مركزية (Active Directory / SSO):** إدارة بديل حسابات محلية معيارية.
* **تشفير كامل لقاعدة البيانات أثناء السكون (Encryption at Rest):** وإدارة مفاتيح عبر HSM/KMS مخصصة.
* **إعادة توجيه سجلات الحدث إلى نظام SIEM المركزي وتخزين WORM لضمان قابلة للتحقيق على مستوى البنية التحتية بأكملها لا تسبق خطوط القطع فقط.**

| الدور | اسم المستخدم |
| :--- | :--- |
| تقنية المعلومات | `it_admin` |
| الإدارة العليا | `hospital_director` |
